# 🚗 카매니저 — 차량 정비일지 & 차계부

GitHub Pages로 바로 배포 가능한 순수 HTML/CSS/JS 차량 관리 웹앱입니다.

## 주요 기능

- 📊 **대시보드** — 주행거리, 연비, 이번 달 지출, 소모품 상태 한눈에 보기
- ⛽ **주유 기록** — 주유량/단가 입력 시 연비 자동 계산, 평균 연비 추적
- 🔧 **정비 기록** — 정비 항목별 이력 관리 (엔진오일, 타이어, 브레이크 등)
- ⏱️ **소모품 관리** — 교체주기 대비 경과 km/일수 표시, 상태 색상 경고
- 💳 **기타 지출** — 보험료, 자동차세, 주차비 등 카테고리별 관리
- 📈 **통계** — 월별 지출 바차트, 카테고리별 도넛차트, 연비 추이 라인차트

## 설치 & 배포

### GitHub Pages 배포 방법

1. 이 저장소를 GitHub에 업로드
2. 저장소 Settings → Pages → Source: `main` 브랜치 `/root` 선택
3. 배포 완료! `https://{username}.github.io/{repo-name}/`

### 로컬 실행

```bash
# 아무 웹서버로 실행 가능 (파일 더블클릭도 OK)
npx serve .
# 또는
python -m http.server 8080
```

## 데이터 저장

- 모든 데이터는 브라우저 **localStorage**에 저장됩니다 (서버 불필요)
- **데이터 내보내기** 버튼으로 JSON 백업 가능
- **데이터 불러오기** 버튼으로 다른 기기로 이전 가능
- 다중 차량 지원
